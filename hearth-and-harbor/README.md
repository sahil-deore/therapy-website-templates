# Hearth & Harbor — Calm Editorial / Distinctive

An agency-ready therapist website **demo template** built with Next.js App Router, TypeScript, React, Tailwind CSS v4 and Lucide. All people, qualifications, service area, and business details are fictional placeholders.

## Quick start

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Customizing for a client

1. Edit `content/site.ts` for all text, specialties, FAQs, contact and service area.
2. Change the CSS tokens at the top of `app/globals.css` for colors and typography.
3. Replace the custom CSS still-life illustrations with licensed real client portraits and office imagery (or keep them as a demo-only artistic direction).
4. Replace the `mailto:` CTA with the client's verified secure booking link; avoid collecting sensitive health information through a generic contact form.
5. Confirm actual credentials, licensing jurisdictions, insurance, rates, telehealth availability, privacy policy, accessibility and required disclosures.
6. Remove `robots: { index: false }` from `app/layout.tsx` only when the real site is ready to be indexed.

## Design direction

**Distinctive Calm Editorial**: asymmetric type-led hero, architectural illustration, sparse use of terracotta accent, restrained typography, service rows rather than card grids, clear first-step CTA, practical logistics, and no fabricated social proof.

## Research / process

- GitHub: https://github.com/rwcod/anti-ai-slop-ui — start with product-specific design intent, tokens, layout and anti-slop review.
- GitHub: https://github.com/wpgaurav/design-slop — avoid decorative clutter and fake affordances.
- https://www.simplepractice.com/blog/top-therapist-websites/ — clear therapist positioning, visible contact action and mobile navigation.
- https://psychology.com/practice-guides/therapist-website-examples — visible logistics, fees and honest trust signals.
- https://nextjs.org/docs/app — Next.js App Router conventions.

## Demo constraints

- This is a polished coded prototype, not a published therapist site.
- No invented reviews, conversion metrics or claims of clinical outcomes.
- The demo consultation link is a placeholder email.
- Artwork is generated with CSS, so no external stock-image service or licensing dependency is required.
