# Stillwater Therapy — Next.js + Tailwind draft

A responsive, editorial-style sample site for a solo therapy practice. Not intended to be published until the placeholder content is replaced and verified.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Replace before launch

- Practice name, therapist biography, headshot, credentials, specialties, actual practice location and jurisdictions
- Sample fees, insurance policies, virtual/in-person availability
- `hello@example.com` email links with a real consultation flow (ideally an appropriately secured intake/scheduling vendor)
- Placeholder photos with properly licensed, client-approved original photography
- Privacy notice, consent/disclaimers, local regulatory disclosures, crisis resources, and correct legal requirements
- Add real About, Specialties, Fees, and Contact routes if the practice needs indexable pages

## Design decisions

- Quiet editorial typography (Cormorant Garamond + DM Sans) instead of default SaaS visuals
- Warm ivory + restrained sage, clean section transitions, no cards-for-everything
- Single clear consultation action; accessible nav and FAQ interactions
- Minimal dependencies; Next.js App Router + Tailwind CSS v4
